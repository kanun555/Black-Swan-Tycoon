# Black Swan Tycoon

เกมบริหารธุรกิจบนเว็บ **รอดวิกฤต รวยโอกาส** เลือกบริษัทของคุณ แข่งกับ AI อ่านข่าว และกล้าเดิมพันกับเหตุการณ์ที่แทบไม่มีใครเชื่อ

**[▶ เล่นเลย](https://kanun555.github.io/Black-Swan-Tycoon/)** (เล่นฟรี ไม่ต้องลงทะเบียน ใช้ได้ทั้งคอมพิวเตอร์และมือถือ)

## เป้าหมาย

บริหารบริษัทให้ครบ **52 สัปดาห์** และทำมูลค่าสุทธิ (เงินสด + สินทรัพย์ − หนี้) ให้มากกว่าคู่แข่ง AI โดยเงินสดห้ามต่ำกว่า **-30,000** ไม่เช่นนั้นถือว่าล้มละลาย

## วิธีเล่น

1. **เลือกบริษัท** 1 จาก 8 อุตสาหกรรม
2. **ตัดสินใจรายสัปดาห์:** ปรับราคาขาย ปรับค่าจ้าง ขยายกำลังผลิต กู้หรือคืนเงิน
3. **กด "จบสัปดาห์นี้"** เพื่อดูผลกำไรขาดทุน แล้วทำซ้ำ
4. **จับตาเมืองด้านบน** ภาพเมืองจะเปลี่ยนตามเหตุการณ์จริง เช่น น้ำท่วม ประท้วง หรือสัญญาณถูกแฮก

## ระบบหลัก

**8 ธุรกิจที่เลือกได้:** พลังงาน, เกษตร, โรงงาน, อาหารแปรรูป, ขนส่ง, เทคโนโลยี, ค้าปลีก, ก่อสร้าง

**ห่วงโซ่อุปทาน:** ธุรกิจส่วนใหญ่ต้องซื้อวัตถุดิบจากอุตสาหกรรมอื่น (เช่น โรงงานซื้อไฟฟ้า ค้าปลีกซื้อสินค้าจากโรงงาน) ถ้าราคาต้นน้ำพุ่ง ต้นทุนคุณพุ่งตาม

**การเงินและบุคลากร:** ราคาตลาดผันผวนตามอุปสงค์และอุปทาน มีดอกเบี้ยเงินกู้ ภาษี 20% และค่าเสื่อมราคา ถ้าพนักงานไม่พอใจมากเกินไปจะนัดหยุดงาน

**เหตุการณ์สองด้าน:** โรคระบาด น้ำท่วม แฮกเกอร์ เงินเฟ้อ ประท้วง เทศกาลช้อปปิ้ง และพายุสุริยะ (Black Swan) แต่ละเหตุการณ์ทำร้ายบางธุรกิจและเป็นโอกาสของบางธุรกิจ และ AI จะปรับตัวทันทีที่มีข่าว

**ข่าวกรอง 3 ช่องทาง:**

| ช่องทาง | ความน่าเชื่อถือ | ข้อดี/ข้อเสีย |
|---|---|---|
| ข่าวหลัก | แม่นยำ | AI รู้พร้อมคุณ ไม่มีใครได้เปรียบ |
| ข่าวลือโซเชียล | พอเชื่อได้ | มาก่อนล่วงหน้า แต่บางเรื่องเป็นของปลอม |
| หมอดูและสตรีมเมอร์ | เกิดจริงน้อยมาก | ถ้าเดิมพันถูก ได้เงินคืนหลายเท่าและคุมตลาด 3 สัปดาห์ |
